# 个人网站设计方案

## 概述

一个综合型个人网站，包含关于我、文章、摄影作品、个人项目四个模块。设计风格借鉴小米官网——白底大留白、小米橙点缀、卡片系统、细腻微动效。全屏滚动单页架构，每个模块独立整页，鼠标滚轮上下切换。

**设计原则：** 有态度、无 AI 味。避免蓝紫渐变、毛玻璃、几何线框等套路化元素。追求克制的科技感、刻意的排版层次、有理由的动效。

---

## 技术选型

| 技术 | 用途 |
|------|------|
| Next.js | 前端框架，SSG 静态生成 |
| GSAP + ScrollTrigger | 滚动驱动动画，页面切换过渡 |
| Lenis | 平滑惯性滚动 |
| Markdown + 配置文件 | 内容管理，所有文字/图片/链接可编辑替换 |
| Tailwind CSS | 样式系统，统一设计令牌 |
| Vercel | 免费托管部署 |

## 网站结构

```
首页入口
  ├── 0_关于我 (About)
  ├── 1_文章 (Articles)
  ├── 2_摄影 (Photography)
  └── 3_项目 (Projects)
      ├── 文章详情页
      ├── 摄影详情页
      └── 项目详情页
```

5 个主页面 + 3 类详情页。全屏滚动切换，右侧固定导航点指示当前位置。

## 页面设计

### 0_关于我 — 方案 C：左图右文杂志编辑感

- **布局：** 左侧 45% 满版大图，右侧 55% 文字内容区，整体无上下内边距，撑满视口
- **照片区域：** 占左侧全部高度，右上角悬浮小米橙圆形装饰图标
- **文字区域（从上到下）：**
  - 英文小标签 "ABOUT ME"（10px，letter-spacing 3px，灰色）
  - 姓名大标题（36px/700，黑色）
  - 小米橙短分割线（40px 宽，3px 高）
  - 个人简介段落（14px，灰色 #666，行高 1.8，最大宽 400px）
  - 联系图标横排（邮箱/文章/GitHub/X），圆形 SVG 图标，直径 38px
  - 数据统计横排（12+ 文章 / 200+ 摄影 / 8 项目），上部有分割线
- **配色：** 纯白底 + 深灰文字 + 小米橙点缀

### 1_文章 — 精选 Hero + 三列网格

- **页面标题区：** "ARTICLES" 英文标签 + "文章 & 思考" 大标题 + 副标题
- **精选文章 Hero 卡片：** 左图（360×220）右文，FEATURED 橙标签，标题 22px/700，摘要+日期
- **文章列表：** 三列卡片网格，每张含封面图（120px 高）+ 标题（14px/600）+ 日期
- **配色：** 浅灰底 #fafafa，白色卡片，暗色文字

### 2_摄影 — 分类标签 + 不规则画廊

- **页面标题区：** "GALLERY" 英文标签 + "摄影作品" 大标题 + 副标题
- **分类标签栏：** 横向排列（全部/风景/城市/人文/黑白），当前选中项有底部橙色下划线
- **画廊网格：** 不规则网格布局，左侧主作品占 2 行，右侧 4 张小图 2×2 排列
- **配色：** 纯白底，浅灰占位图，暗色文字

### 3_项目 — 左右交替图文卡片

- **页面标题区：** "PROJECTS" 英文标签 + "个人项目" 大标题 + 副标题
- **项目卡片列表：** 纵向排列，每张卡片内左右交替布局
  - 卡片 1：左图（340×200）右文
  - 卡片 2：左文右图（340×200）
- **每张卡片内容：** 类型标签（WEB APP/TOOL 等，橙字）+ 项目名（20px/700）+ 描述（12px 灰色）+ 技术标签（9px 浅灰底圆角）
- **配色：** 浅灰底 #fafafa，白色卡片

## 详情页设计

### 文章详情页

- **布局：** 内容区 720px 居中，窄栏舒适阅读宽度
- **页面结构：**
  - 分类标签 + 日期（橙字）
  - 文章标题（32px/700）
  - 作者行：头像圆 + 名字 + 阅读时长
  - 正文区域：段落（14px，行高 2），小标题（18px/600），插图（全宽圆角），引用块（左边框橙色）
- **入场动效：** 内容从下方 30px 淡入上移 0.6s；段落滚动到视口时逐段淡入，stagger 0.1s；图片 scale(0.95→1) 淡入

### 摄影详情页

- **布局：** 内容区 1000px 居中
- **页面结构：**
  - 顶部操作栏：标题（28px/700）+ 分类日期标签 + 返回/下一张导航
  - 大图区域：16:9 全宽，圆角 10px
  - 底部信息栏：仅地点信息（图标 + 文字），无相机/镜头/参数
- **入场动效：** 大图从上方滑入 0.5s；地点信息延迟 0.2s 淡入

### 项目详情页

- **布局：** 内容区 900px 居中
- **页面结构：**
  - 类型标签 + 项目标题（28px/700）+ 描述
  - 技术栈标签行
  - 外链按钮（在线访问 + 源代码，圆角 20px 药丸按钮）
  - 项目主图（全宽 260px 高）
  - 项目背景/技术实现正文
- **入场动效：** 标题先入 → 描述 → 标签 staggered 依次出场 0.08s；截图 scale(0.96→1) 淡入

## 交互动效规范

### 统一动效令牌

| 令牌 | 值 | 用途 |
|------|-----|------|
| hover 过渡 | 0.25s ease | 图标/按钮/标签 |
| 卡片 hover | 0.3s ease-out | 卡片上浮+阴影 |
| 页面进入 | 0.5-0.6s ease-out | 内容淡入上移 |
| stagger 间隔 | 0.08-0.15s | 列表项依次出场 |
| 缓动函数 | cubic-bezier(.25,.8,.5,1) | 全局统一 |

### 卡片 Hover 效果

- **文章卡片：** 上移 4px + 阴影加深扩散 + 封面亮度提升 10%，0.3s
- **摄影卡片：** 上移 3px + 微放大 scale(1.02) + 底部渐变标题浮出，0.35s
- **项目卡片：** 上移 4px + 阴影加深 + 技术标签背景微微变深，0.3s
- **移开还原：** 所有 hover 效果鼠标移开后平滑回落

### 联系图标 Hover

- 边框变小米橙 #ff6700（1.5px）
- 内部 SVG 图标变小米橙
- 上浮 translateY(-2px)
- 橙光阴影 box-shadow: 0 2px 8px rgba(255,103,0,0.15)
- 过渡 0.25s ease，移开还原

### 页面切换动画（4 种不重复）

| 过渡 | 方向 | 效果 | 时长 |
|------|------|------|------|
| 首页 → 文章 | ↓ | 淡入 + 微缩放 0.98→1 | 0.8s |
| 文章 → 摄影 | ↓ | 水平百叶窗（3 条依次拉开） | 0.6s/条 |
| 摄影 → 项目 | ↓ | 视差淡入（上层快移，下层慢跟 1:0.3） | 1.0s |
| 任意 → 关于 | ↑ | 错位滑入（左右交替 0.15s stagger） | 0.8s |

### 详情页返回按钮

- hover 文字变橙 + 箭头左移 4px，0.25s

### 摄影分类标签

- 点击切换时橙色下划线平滑滑动到目标标签，0.3s

## 内容管理方案

所有网站上展示的内容通过以下方式管理，无需修改代码：

- **个人信息：** `data/profile.json` — 姓名、简介、照片路径、邮箱、社交链接
- **文章：** `content/articles/*.md` — Markdown 格式，Frontmatter 包含标题/日期/分类/封面图
- **摄影作品：** `content/photos/*.md` — 每张作品一个文件，含标题/分类/地点/图片路径
- **项目：** `content/projects/*.md` — 含标题/类型/描述/技术栈/链接/截图

新增内容只需添加新文件，现有内容编辑后重新构建即可生效。
